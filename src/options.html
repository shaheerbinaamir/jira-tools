    Bitbucket commit heatmap

    Shows commit activity across a workspace as a GitHub-profile-style heatmap — yours by default, or anyone else's by typing their Bitbucket username in the tab itself. Bitbucket has no single "activity" feed, so this scans every repo's default branch in the workspace below (or a fixed list) for that person's commits. App passwords are deprecated — instead create a scoped API token at id.atlassian.com/manage-profile/security/api-tokens with the read:repository:bitbucket and read:account:bitbucket scopes.

    Strongly recommended. Bitbucket can't filter commits by author server-side, so scanning every repo in a busy workspace means paging through everyone's commit history before it can be filtered down to yours — which is slow and can trip Bitbucket's rate limit. Listing just the repos you actually commit to here skips the workspace-wide scan entirely and is dramatically faster.

    Data & privacy

    • No analytics, no telemetry, no crash reporting, no remote code.
    • The only network requests are to the Atlassian sites listed above, plus api.bitbucket.org if you configure the commit heatmap.
    • Everything it remembers lives in chrome.storage.local on this machine.
